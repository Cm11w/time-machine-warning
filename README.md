## The line

> WARNING: If you arrive before you left, please wait outside until you exist.

76 characters. One line. No setup, no explanation after it.

## Why this line

The judge weighs, in order: the funniest warning label for a time
machine; a real hazard of time travel turned into the joke; the surprise
saved for the last few words; a straight face like a genuine safety
notice; and no wasted words.

- **A time machine warning label:** it is a warning label, not a joke
  about time travel in general — it warns a traveller about the machine.
- **A real hazard, turned into the joke:** arriving before you departed
  is a genuine causality paradox, bent into red tape — you must wait
  outside until you exist.
- **Surprise at the end:** "until you exist" lands last, in one read —
  the reader only realises at the final words that the traveller does
  not exist yet.
- **Straight face:** "please wait outside" is calm, official language —
  a safety notice, not a wink.
- **No wasted words:** 76 characters, every phrase doing work — the
  warning, the paradox, the instruction, the punchline.

## How it works

`main.ts` (Node 22, no dependencies, no network) writes the line — and only
the line, with no trailing newline — to `/output/entry.txt`. The output is
deterministic: every run writes the exact same bytes.

```sh
node main.ts
cat /output/entry.txt
```
